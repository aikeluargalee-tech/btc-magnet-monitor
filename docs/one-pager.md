# BTC Magnet — One-Page Product Definition
*(Locked)*

### 1. Single Job
A person opens the app to answer one question:  
**“What is currently pulling Bitcoin, and is there a clear swing edge or not?”**

### 2. First Screen (what the user sees)
- Current Bitcoin price and 24h change.
- One simplified visual showing the main magnet zones.
- One short plain-language card that states the current situation and status.
- Clear status line: either a high-conviction note or the default **“No clear edge — wait.”**
- Share button that creates a clean “Magnet Card” image.
- Nothing else on the first screen.

### 3. When It Speaks (internal logic)
The app defaults to **“No clear edge — wait.”**  
It only shows a high-conviction note when a small set of strict conditions align. Those conditions are evaluated internally and include:

- A meaningful liquidation magnet
- Supporting open-interest behavior
- Funding rate context
- Current regime (range vs trend)
- Basic price structure / spot-flow confirmation

### 4. Free vs Premium
- **Free**: Live magnet visual + short explanation + share card.
- **Premium** (later): Fuller context, history, optional alerts.

First version is 100% free.

### 5. Success after 30 Days
- People open it regularly.
- Users share the Magnet Card.
- Users understand the status without a tutorial.
- The app spends most days correctly saying “wait.”

### Design Principles
- Magnet-centered and plain-language on the surface.
- Open interest, funding, and regime used as internal filters only.
- Selective and honest by default.
- Visual style: modern dark interface with restrained retro character.
