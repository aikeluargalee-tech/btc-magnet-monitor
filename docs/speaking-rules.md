# BTC Magnet — Rules for Speaking
*(Locked)*

The app defaults to **“No clear edge — wait.”**  
It only changes that status when **all** of the following conditions are true.

### Strict conditions required to speak
1. **Clear magnet present** — meaningful liquidation cluster within practical distance.
2. **Open-interest confirmation** — OI rising into the magnet or recently expanded on the relevant side.
3. **Funding context is not contradictory** — neutral or elevated in the supporting direction.
4. **Regime allows the magnet to matter** — range = primary; strong trend = only if aligned or exhaustion.
5. **Basic structure / spot-flow alignment** — no strong contradiction.
6. **Not already played** — cluster not recently swept.
7. **Minimum conviction threshold** — at least four of the above cleanly met, none in direct conflict.

Borderline cases stay on “wait.”
