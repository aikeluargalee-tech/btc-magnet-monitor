# BTC Magnet

A free, mechanics-first Bitcoin intelligence tool that answers one question only:  
**“What is currently pulling Bitcoin, and is there a clear swing edge or not?”**

Defaults to **“No clear edge — wait.”** and only speaks when strict internal conditions align.

---

## 🚀 Live App & Architecture
- **Single-Screen Web App**: `index.html` (root) and `prototype/index.html`
- **Design System**: Modern dark fintech with restrained retro character (cyber cyan `#00f0ff` & amber `#ffb020` on obsidian `#07090e`).
- **Internal Rules Engine**: Evaluates the 7 locked speaking rules (Liquidation Clusters, Open Interest velocity, Funding carry, Regime conduciveness, Spot flow structure, Unswept check, and Conviction threshold).
- **Shareable Magnet Card**: High-resolution 1080×1350 canvas card generator with native Web Share API and PNG download fallback.
